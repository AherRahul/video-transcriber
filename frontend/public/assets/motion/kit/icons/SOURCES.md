# Icons - source

**Lucide** 0.460.0 (https://lucide.dev), ISC licence (LICENSE.txt here): 1,539 line icons on a 24 x 24 grid.
lucide.json holds each icon's inner SVG markup and tags.json its search words, written by
frontend/scripts/build-kit-icons.mjs from the lucide-static package (read as files, not a dependency).
